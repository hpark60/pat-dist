# pat-dist

## RN 공정 배정 도구

브라우저에서 [RN 공정 배정 도구](https://hpark60.github.io/pat-dist/)를 열어 사용할 수 있습니다.

1. 의사별 환자 수를 한 줄에 입력합니다. 의사 이름과 환자 수는 공백, 쉼표 또는 탭으로 구분합니다.
2. 간호사 수를 선택하고 **배정하기**를 누릅니다.
3. 결과 표를 확인하고, 필요하면 배정 결과를 PNG 이미지로 저장합니다.

별도 설치 없이 브라우저에서 실행됩니다. 배포는 `main` 브랜치에 변경 사항이 올라올 때 GitHub Actions로 자동 수행됩니다.
